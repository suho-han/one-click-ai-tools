# zsh / oh-my-zsh 통합 (completion + statusline zsh 타깃)

## 목적

oh-my-zsh 사용자가 oct를 자연스럽게 쓰도록 두 가지를 추가한다. OMZ 번들 플러그인 PR은
범위에서 제외하고, oct가 직접 생성물을 내는 방식(OMZ/prezto/plain zsh 공통)으로 간다.

1. `oct completion <bash|zsh|fish>` — 셸 완성 스크립트 출력
2. `oct statusline config zsh` — zsh 통합 스니펫 출력 (완성 캐시 + 프롬프트 세그먼트)

## 1. completion 커맨드

- 새 파일 `cmd/completion.go` (빌드 태그 없음).
- `Use: "completion <bash|zsh|fish>"`, `GroupID: "maintenance"`, `Short: "Print a shell completion script"`.
- `Args: cobra.MaximumNArgs(1)`. 인자 없음/미지원 셸이면 `&usageError{...}` 반환(exit 2)
  하고 stderr에 지원 목록과 예시를 출력한다. 기존 `statuslineResolveTarget`의 실패 문구 톤을 따른다.
- 생성은 cobra 내장 메서드만 사용: `rootCmd.GenBashCompletionV2(w, true)`,
  `rootCmd.GenZshCompletion(w)`, `rootCmd.GenFishCompletion(w, true)`. 새 의존성 없음.
- 출력은 stdout, 안내는 stderr. `rootCmd.CompletionOptions{DisableDefaultCmd: true}`는 그대로 둔다
  (기본 completion 커맨드가 되살아나면 이 커맨드와 중복된다).
- `ValidArgs: []string{"bash", "zsh", "fish"}`로 자체 완성도 동작하게 한다.

## 2. statusline zsh 타깃

- `statuslineConfigTargets`에 `"zsh"`를 마지막에 추가. `statuslineInstallTargets`는 변경하지 않는다
  (zsh는 파일을 쓰지 않고 붙여넣기용 스니펫만 낸다).
- `statuslineCmd.Short`, `statuslineConfigCmd.Use` 문구에 zsh를 반영.
- `statuslineSnippet`에 `case "zsh"` 추가. 스니펫은 `--path`로 받은 oct 경로를
  `statuslineQuote`로 감싸 하드코딩한다(다른 타깃과 동일 규칙).

스니펫이 해야 하는 일:

```zsh
# oct — zsh integration (generated by: oct statusline config zsh)
# Oh My Zsh: save as $ZSH_CUSTOM/plugins/oct/oct.plugin.zsh, then add oct to plugins=(...)
# plain zsh: source this file from ~/.zshrc after compinit
if [[ ! -x <oct> ]] && (( ! $+commands[oct] )); then
  return
fi

# --- completion (cached) ---
if [[ -n $ZSH_CACHE_DIR ]]; then
  _oct_completion_dir="$ZSH_CACHE_DIR/completions"
else
  _oct_completion_dir="${XDG_CACHE_HOME:-$HOME/.cache}/oct/completions"
fi
[[ -d $_oct_completion_dir ]] || mkdir -p $_oct_completion_dir
if [[ ! -s $_oct_completion_dir/_oct ]]; then
  <oct> completion zsh >| $_oct_completion_dir/_oct 2>/dev/null
fi
if [[ -s $_oct_completion_dir/_oct ]]; then
  fpath=($_oct_completion_dir $fpath)
  (( $+functions[compdef] )) && compdef _oct oct
fi

# --- prompt segment (opt in with OCT_PROMPT=1) ---
# Reads the last `oct monitor` snapshot; no provider/network calls per prompt.
typeset -g _oct_prompt_segment=""
typeset -g _oct_prompt_last=0

_oct_prompt_refresh() {
  (( _oct_prompt_last != 0 && SECONDS - _oct_prompt_last < ${OCT_PROMPT_INTERVAL:-5} )) && return
  _oct_prompt_last=$SECONDS
  local out
  out=$(<oct> usage --format compact --from-snapshot 2>/dev/null) || return
  _oct_prompt_segment=${out//$'\n'/ }
}

if [[ ${OCT_PROMPT:-0} == 1 ]]; then
  autoload -Uz add-zsh-hook
  add-zsh-hook precmd _oct_prompt_refresh
  typeset -g _oct_rprompt_base=$RPROMPT
  RPROMPT='${_oct_prompt_segment}${_oct_prompt_segment:+" "}${_oct_rprompt_base}'
fi
```

주의: `zmodload zsh/datetime` 없이 동작하도록 `EPOCHSECONDS`가 아니라 `SECONDS`를 쓴다.
precmd 훅은 동기 호출이지만 throttle(기본 5초) + snapshot 렌더(실측 ~4ms)라 예산 안이다.

## 3. `oct statusline install zsh` (추가 작업)

`config zsh`는 붙여넣기용이므로, Oh My Zsh 사용자를 위해 파일 설치 경로를 추가한다.
`.zshrc`는 절대 수정하지 않고, 설치 위치와 다음 단계만 안내한다.

CLI 표면:

```
oct statusline install zsh [--dir DIR] [--force]
```

- `statuslineInstallTargets`에 `"zsh"` 추가. `statuslineConfigTargets`는 그대로(이미 포함).
- 파일명은 타깃별로 다르다: swiftbar/xbar → `oct.5m.sh`, zsh → `oct.plugin.zsh`.
  `statuslinePluginFileName(target) string` 헬퍼로 분리한다.
- 파일 모드도 다르다: swiftbar/xbar → 0755, zsh → 0644.
- 기본 디렉터리(`statuslineDefaultDir`):
  1. `$ZSH_CUSTOM`이 있으면 `$ZSH_CUSTOM/plugins/oct`
  2. 없고 `~/.oh-my-zsh/custom`이 디렉터리로 존재하면 그 아래 `plugins/oct`
  3. 둘 다 없으면 에러: Oh My Zsh 미검출 → `--dir`을 쓰라고 안내
     (예: `--dir ~/.config/oct/zsh`), 그리고 `oct statusline config zsh`로 수동 설치 가능함을 언급
- 기존 `--force` 규칙 유지: 없으면 `O_EXCL`, 이미 있으면 "already exists; pass --force to overwrite".
- Windows는 기존 install 거부 로직이 그대로 적용된다.
- 설치 후 안내(타깃별):
  - swiftbar/xbar: 기존 두 줄 유지
  - zsh: `Installed <dest>` + `Add oct to plugins=(...) in ~/.zshrc, then start a new shell.`
    + `Optional: export OCT_PROMPT=1 before Oh My Zsh loads to show a usage segment in RPROMPT.`

테스트(`cmd/statusline_test.go`):

- `$ZSH_CUSTOM` 지정 시 dir이 `$ZSH_CUSTOM/plugins/oct`인지, 미설정 + `~/.oh-my-zsh/custom`
  존재 시 fallback, 둘 다 없으면 `--dir`을 요구하는 에러 (홈은 `t.Setenv("HOME", t.TempDir())`로 격리)
- 임시 dir에 설치 시 `oct.plugin.zsh`가 0644로 생성되고 내용이
  `statuslineSnippet("zsh", execPath)`와 일치
- `--force` 없이 재실행하면 실패, `--force` 있으면 덮어씀
- swiftbar/xbar 설치 동작·파일명·0755는 기존 테스트로 계속 보장(변경 금지)
- `runStatuslineInstall`은 이미 `goos` 인자를 받으므로 windows 거부도 그대로 검증
