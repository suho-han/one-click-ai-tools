# Roadmap & Canonical Command Map (2026-09-12)

Product positioning, canonical command order, and phased plan derived from the
2026-09-12 competitive scan. This is the strategy doc; [todo.md](todo.md)
stays the flat backlog.

## Positioning (canonical thesis)

- EN: **"One binary that organizes your AI coding CLIs — update them all,
  watch every quota plan, schedule the maintenance."**
- KO: "AI 코딩 CLI를 하나의 바이너리로 정리한다 — 전부 업데이트, 전부 쿼터 감시,
  유지보수 예약."

Rationale (see [competitive_landscape_2026-09-12.md](competitive_landscape_2026-09-12.md)):
usage aggregation alone is saturated (CodexBar 21k★ covers GLM/Kimi/Qwen/
MiniMax live plus menubar; caut is its CLI+`--json` port), while the
AI-specific updater is near-empty (agentmgr 35★ is the only peer) and the
update+usage combination is unoccupied. Every user-facing surface should lead
with the combination, never with "usage tool".

The three pillars map to commands:

| Pillar | EN | Commands |
| --- | --- | --- |
| 전부 업데이트 | update them all | `agent-update` |
| 전부 쿼터 감시 | watch every quota plan | `usage`, `monitor`, `menubar`, `alert` |
| 유지보수 예약 | schedule the maintenance | `schedule`, `session-refresh` |

## Canonical command order (workflow order for docs)

Docs/README present commands in this setup → daily → scheduled → diagnostics
order (README KR/EN restructured to this on 2026-09-12):

1. Setup: `oct config`
2. Update: `oct agent-update` (`--dry-run --explain` first)
3. Watch: `oct usage` (`--json`/`--compact`/`--notify`), `oct monitor`, `oct menubar`
4. Alert: `oct alert config …`, snooze
5. Schedule: `oct schedule enable --task …`, `oct session-refresh`
6. Diagnostics: `oct doctor`, `oct update`, `oct release-doctor`

`oct --help` intentionally keeps its frequency-based grouping (Core =
usage/monitor/menubar; Configuration & Scheduling = config/alert/schedule;
Update & Maintenance = agent-update/session-refresh/release-doctor/doctor/
update). The thesis lives in README/repo description, not in help ordering —
usage is the most frequent daily verb and should stay the first help entry.
